# 标的资产模糊搜索过滤功能

## 功能概述

在订单簿监控页面添加了标的资产(Base Asset)的模糊搜索下拉框过滤功能,替代原有的静态文本标题。

## 功能特性

### 1. 模糊搜索
- ✅ 支持输入关键字实时过滤标的资产
- ✅ 不区分大小写 (如: 输入 "btc" 可匹配 "BTC")
- ✅ 支持部分匹配 (如: 输入 "B" 可匹配 "BTC", "ETH", "BNB" 等)

### 2. 下拉选项
- ✅ 自动从当前数据中提取所有唯一的标的资产
- ✅ 最多显示 10 个匹配选项
- ✅ 点击选项即可快速选择
- ✅ 点击外部区域自动关闭下拉框

### 3. 清除过滤
- ✅ 输入框带清除按钮,一键清空过滤条件
- ✅ 清空后显示所有标的资产数据

## 使用方法

### 搜索标的资产
1. 在页面顶部的搜索框中输入关键字 (如: "BTC", "ETH")
2. 下拉列表会实时显示匹配的标的资产
3. 点击 desired 的标的资产即可过滤

### 清除过滤
- 点击输入框右侧的 "×" 清除按钮
- 或直接删除输入框中的文字

## 技术实现

### 数据过滤逻辑

#### 1. 提取唯一标的资产
```typescript
const uniqueAssets = computed(() => {
  const assets = new Set<string>()
  rowData.value.forEach(row => {
    if (row.base_asset) {
      assets.add(row.base_asset)
    }
  })
  return Array.from(assets).sort()
})
```

#### 2. 模糊搜索过滤
```typescript
const filteredAssetOptions = computed(() => {
  if (!assetFilterKeyword.value) {
    return uniqueAssets.value
  }
  const keyword = assetFilterKeyword.value.toLowerCase()
  return uniqueAssets.value.filter(asset => 
    asset.toLowerCase().includes(keyword)
  )
})
```

#### 3. AG Grid 外部过滤
```typescript
function assetFilterFunc(params: any): boolean {
  if (!assetFilterKeyword.value) return true
  const data = params.data as OrderBookRow
  if (!data) return true
  const baseAsset = data.base_asset
  if (!baseAsset) return true
  return baseAsset.toLowerCase().includes(assetFilterKeyword.value.toLowerCase())
}
```

### 事件处理

#### 选择资产
```typescript
function selectAsset(asset: string) {
  assetFilterKeyword.value = asset
  assetFilterVisible.value = false
}
```

#### 点击外部关闭
```typescript
function handleOutsideClick(event: MouseEvent) {
  const target = event.target as HTMLElement
  if (!target.closest('.asset-filter-container')) {
    assetFilterVisible.value = false
  }
}
```

## 与其他过滤功能的集成

标的资产过滤与现有的三个过滤开关集成在一起:
1. ✅ 资金费率过滤
2. ✅ 开仓盘口阈值过滤
3. ✅ VWAP基差阈值过滤
4. ✅ **标的资产过滤** (新增)

所有过滤条件使用 AND 逻辑组合:
```typescript
function combinedFilterFunc(params: any): boolean {
  return fundingRateFilterFunc(params) 
    && coverageFilterFunc(params) 
    && marginalBasisFilterFunc(params) 
    && assetFilterFunc(params)
}
```

## 注意事项

1. **性能优化**: 标的资产列表通过 `computed` 缓存,仅在数据变化时重新计算
2. **内存管理**: 在 `onUnmounted` 中清理事件监听,避免内存泄漏
3. **大小写不敏感**: 搜索时自动转换为小写进行比较
4. **空值处理**: 过滤函数对空值有完善的兜底逻辑
