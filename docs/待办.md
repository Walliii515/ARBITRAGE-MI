# 待办事项

## 1. Gate 期货 Maker 模式改造（费率优化）

**背景**：当前 4 腿全 taker，总费率 25 bps（Binance 现货 7.5×2 + Gate 期货 5×2），利润基本被手续费消耗。

**当前已落地**：先做开仓 Gate future maker + Binance spot taker。开仓 Gate future 费率按 2 bps 计，平仓 Gate future 仍是保护性 IOC/taker 5 bps，因此当前完整一轮总费率口径为 22 bps。若后续平仓 Gate future 也稳定改为 maker，完整一轮可继续降至 19 bps。

**实施方案**：
- 开仓执行模式从“并发双 taker”改为“Gate future post-only maker → Binance spot taker”
- Gate 期货端挂 post-only 限价单，短 TTL 内未成交则撤单并放弃本轮信号，不触发现货腿
- Gate 期货部分成交时，立即按已成交数量用 Binance 现货市价买入对冲
- 开仓/平仓原因会记录 `future_maker`、`fill`、`wait`、`maker_px`、`future_px`、`spot_px`、`improve`

**风险点**：
- maker 单可能不成交（小币种深度薄）
- Gate 成交到 Binance 执行之间有 ~100ms 时间窗口
- Binance spot hedge 失败时仍会产生期货单边风险，需要人工处理

**后续观察指标**：
- `maker_fill_ratio`：future maker 成交比例
- `maker_wait_ms`：maker 等待耗时
- `actual_basis_bps`：成交后真实基差
- `improvement_bps`：future maker 相对原 future taker VWAP 的改善
