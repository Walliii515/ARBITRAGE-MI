# 待办事项

## 1. Gate 期货 Maker 模式改造（费率优化）

**背景**：当前 4 腿全 taker，总费率 25 bps（Binance 现货 7.5×2 + Gate 期货 5×2），利润基本被手续费消耗。

**目标**：Gate 期货两腿改为 maker（2 bps），总费率降至 19 bps，每轮省 6 bps。

**实施方案**：
- 执行模式从"并发双 taker"改为"串行 maker→taker"
- Gate 期货端挂限价单（maker），成交后立即 Binance 现货市价单（taker）
- 需新增：
  1. Gate 订单状态 WS 监听（`futures.orders` 频道）
  2. 订单状态机（挂单 → 成交 → 触发对冲 → 超时撤单）
  3. 单边成交补偿逻辑（Gate 成交但 Binance 失败时的处理）

**风险点**：
- maker 单可能不成交（小币种深度薄）
- Gate 成交到 Binance 执行之间有 ~100ms 时间窗口
- 架构复杂度上升

**触发条件**：金额放大到 500U+ 时实施，届时每轮可省 0.3 USDT+。
