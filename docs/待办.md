# 待办事项

## 1. Gate 期货 Maker 模式改造（费率优化）

**背景**：当前 4 腿全 taker，总费率 25 bps（Binance 现货 7.5×2 + Gate 期货 5×2），利润基本被手续费消耗。

**当前已落地**：开仓和平仓的 Gate future 腿均优先走 post-only maker；若 maker 未成交且安全垫仍够，会转保护 IOC 兜底。`mi_trade_order` 持久化实际 `liquidity_role` 与手续费字段；Gate/Binance 手续费都会折算到 `fee_amount_usdt`，持仓盈亏优先按订单级真实 USDT 手续费计算，缺失时按账户配置费率估算。Binance spot 仍走 taker。

**实施方案**：
- 开仓执行模式从“并发双 taker”改为“Gate future post-only maker → Binance spot taker”
- 平仓执行模式对称改为“Gate future reduce-only post-only maker → Binance spot taker”
- Gate 期货端挂 post-only 限价单，短 TTL 内未成交则撤单；若安全垫仍够，转保护 IOC 兜底
- Gate 期货 maker 或 fallback IOC 部分成交时，立即按已成交数量用 Binance 现货市价对冲；平仓时按 spot/future 持仓比例折算 spot 卖出数量
- 开仓/平仓原因会记录 `future_maker`、`fill`、`wait`、`maker_px`、`future_px`、`spot_px`、`improve`、`fallback`、`fallback_filled`

**风险点**：
- maker 单可能不成交（小币种深度薄），fallback IOC 可能改善成交率但会牺牲部分 maker 手续费优势
- Gate 成交到 Binance 执行之间有 ~100ms 时间窗口
- Binance spot hedge 失败时仍会产生期货单边风险，需要人工处理

**后续观察指标**：
- `maker_fill_ratio`：future maker 成交比例
- `maker_wait_ms`：maker 等待耗时
- `actual_basis_bps`：成交后真实基差
- `improvement_bps`：future maker 相对原 future taker VWAP 的改善

有，但我不建议简单理解成“哪个交易所 funding 永远比 Gate 好”。更准确是：Gate 属于长尾小币 funding 很肥的一档，但不是唯一一档；MEXC/Bitget/Bybit/Hyperliquid 经常也会出现更好的点。

我会按适合你的优先级排：

交易所	Funding 机会	适合程度	我的判断
Bybit	中高	高	最适合做第二个 CEX futures venue，API 成熟，盘口比 Gate 稳，极端 funding 少一点但执行质量更好
Bitget	中高	高	小币 funding 和覆盖面不错，官方 API 有历史 funding，适合作为 Gate 的直接替补/补充
MEXC	很高	中低	funding 经常很夸张，但盘口、风控、稳定性和信任成本更高，我会先只监控不实盘
Hyperliquid	中高	中	小时级 funding，机制透明，API 好，但资金体系和 CEX 不同，接入复杂度更高
OKX	中	中高	更稳，但 funding 通常没 Gate/Bitget/MEXC 那么肥，适合作为低风险对照组
Binance	中低	高	最稳，但机会最薄，更适合作为基准策略
官方口径上，这些都具备 funding 数据入口：Bybit 有 /v5/market/funding/history，并说明不同 symbol 可能有不同 funding interval；Bitget 的 funding interval 也按 symbol 变化，可通过 instruments 获取；OKX 文档支持 funding rate/history；Hyperliquid 是每小时支付 funding；MEXC 官方也说明 funding 结算时间会因交易对变化，通常但不总是 8 小时。参考：Bybit docs、Bitget docs、OKX docs、Hyperliquid docs、MEXC funding。

对你当前系统，我的建议是：

第一优先：Bybit 或 Bitget。
它们比 MEXC 更适合实盘自动化，比 OKX/Binance 更容易找到肥 funding。你现在已经被 Gate 的追保、ADL、真实手续费、单腿风险折腾过一轮了，第二个交易所最好别选最野的。

第二优先：Hyperliquid。
它的小时级 funding 对你的策略其实很有吸引力，因为你不用等 8 小时，资金费回收更连续。但它不是传统 CEX，资金、签名、风控、账务模型都要单独做。

MEXC 我会先做监控，不马上实盘。
它可能有最高的 funding，但“最高 funding”往往伴随最差盘口、最宽基差、最容易插针和最麻烦的风控事件。你现在的策略核心是稳定吃 carry，不是赌极端小币。

真正应该做的不是替换 Gate，而是加一层 venue scanner：

Binance spot + Bybit future
