# Gate 全仓保证金规则

正向策略固定使用 Gate 全仓模式。现货腿在 Binance，Gate 永续空头腿共享账户保证金，不存在正向逐仓配置、逐币追保或单仓保证金比例。

## 核心口径

系统使用 Gate 账户级风险指标：

```
账户 MMR = Gate 账户权益 / 所有持仓维持保证金合计 * 100
可用率 = Gate 可用资金 / Gate 账户权益 * 100
```

同时读取各合约的强平价，并计算当前价格到最近强平价的距离。单个合约返回的 `position.margin` 不用于正向策略风控，因为全仓模式下它不能代表该币种独占的保证金。

## 开仓风控

- Gate 全仓风险状态为 `warning` 或 `danger` 时，禁止所有正向新开仓。
- Gate 下单后的可用资金不得低于账户总资金的 `15%`。
- 单币集中度由等额 Binance 现货腿控制，普通上限为 Binance 总资金的 `10%`；符合优质加仓条件时最高为 `20%`。
- Gate 不再按币种计算保证金集中度。

## 持仓与平仓风控

- 账户 MMR 或最近强平距离进入危险区时，触发风险平仓检查。
- 风险平仓使用 Gate 市价语义，优先快速、完整地降低全仓风险。
- Gate 期货腿成交后立即处理 Binance 现货腿；断腿由即时对账和自动兜底继续处置。
- 全仓模式不执行逐币追加保证金。账户资金天然共享，风险缓冲通过 Gate 可用资金和账户级 MMR 管理。

## 当前主要配置

```yaml
trade:
  open:
    min_gate_available_ratio: 0.15
    max_asset_exposure_ratio: 0.10
    quality_scale_in:
      enhanced_ratio: 0.20

margin:
  warning_pct: 300
  close_threshold_pct: 200
  danger_path:
    mmr_pct: 300
    liq_distance_bps: 300
```

反向策略如需配置 Gate future 杠杆，使用独立的 `reverse_arbitrage.execution.gate_leverage`。
